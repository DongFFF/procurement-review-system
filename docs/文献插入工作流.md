## 本仓库相关的实现

本仓库保留的是**针对这篇论文的具体实现**，不是通用方法：

| 文件 | 作用 |
|------|------|
| `scripts/zotero_extract_reference.py` | 提取脚本（与上游同源，本地副本便于离线运行） |
| `scripts/zotero_fields.py` | 字段注入、偏好注入、结构自检 |
| `scripts/build_references.py` | CNKI 引文解析 → Zotero 入库 → 参考文献表 |
| `scripts/build_paper.py` | 论文生成（`--zotero` 切换字段版） |
| `docs/论文交付说明.md` | 本论文的交付状态与验证矩阵 |

## 一句话结论

字段结构的参数（URI 里的账户 ID、文档偏好格式、`date-parts` 类型、中文作者形态）
**必须从一份 Zotero 插件真实生成过的文档里读出来，不能猜**。
最典型的两个致命错误：把 `ZOTERO_PREF_1` 写成 JSON（Word 直接判文件损坏），
以及把条目 URI 写成 `users/0`（字段永不与库关联）。

# 桌面端打包说明

本文档说明如何把系统打包成 Windows 桌面 exe 安装包。

## 技术架构

```
┌─────────────────────────────────────────────┐
│  Tauri 外壳（Rust，约 10MB）                 │
│  ┌───────────────────────────────────────┐  │
│  │  WebView2（Windows 内置）              │  │
│  │  └─ React 前端界面                     │  │
│  └───────────────────────────────────────┘  │
│                    ↓ HTTP                   │
│  ┌───────────────────────────────────────┐  │
│  │  Python 后端（FastAPI，子进程）        │  │
│  │  └─ 知识库 / 规则库 / 审查引擎         │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

启动流程：
1. Tauri 启动 → 拉起 Python 后端子进程（`backend/run_server.py`）
2. 轮询 `/api/health` 直到后端就绪
3. 窗口加载 `http://127.0.0.1:8756`
4. 关闭窗口 → 结束后端进程

## 环境准备

### 1. Rust 工具链

```powershell
winget install Rustlang.Rustup
# 安装后重启终端
rustup default stable-msvc
```

### 2. MSVC 生成工具（Rust 编译 Windows 目标必需）

```powershell
winget install Microsoft.VisualStudio.2022.BuildTools
```

安装时勾选 **「使用 C++ 的桌面开发」** 工作负载。

验证：

```powershell
rustc --version
cargo --version
```

### 3. Node.js 与 pnpm

```powershell
winget install OpenJS.NodeJS.LTS
npm install -g pnpm
```

### 4. Python 依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

## 打包步骤

### 一键打包

```powershell
.\scripts\build_desktop.ps1
```

该脚本会依次：
1. 检查 Rust / Node / Python 环境
2. 构建前端（`pnpm run build` → `frontend/dist`）
3. 调用 `tauri build` 生成安装包
4. 输出产物路径

### 手动打包

```powershell
# 1. 构建前端
cd frontend
pnpm install
pnpm run build

# 2. 打包桌面端
cd ..
cd src-tauri
cargo tauri build
```

## 产物位置

```
src-tauri/target/release/bundle/
├── nsis/
│   └── 中直高校采购需求审查系统_0.1.0_x64-setup.exe   ← 安装包
└── msi/
    └── 中直高校采购需求审查系统_0.1.0_x64_en-US.msi
```

NSIS 安装包默认安装到用户目录（`installMode: currentUser`），**无需管理员权限**。

## 关于 Python 运行时

打包后的 exe 需要 Python 环境。有两种方案：

### 方案 A：依赖系统 Python（简单，但用户需装 Python）

`src-tauri/src/main.rs` 中的 `resolve_backend` 会按顺序查找：
1. 资源目录下的 `python-runtime/python.exe`
2. 系统 PATH 中的 `python`

若用户机器没有 Python，会启动失败。

### 方案 B：内嵌 Python 运行时（推荐，真正做到零门槛）

1. 下载 Python embeddable 包（约 15MB）：
   ```powershell
   $ver = "3.12.8"
   Invoke-WebRequest "https://www.python.org/ftp/python/$ver/python-$ver-embed-amd64.zip" -OutFile python-embed.zip
   Expand-Archive python-embed.zip -DestinationPath src-tauri\python-runtime
   ```

2. 启用 site-packages（编辑 `src-tauri/python-runtime/python312._pth`，取消注释 `import site`）

3. 安装依赖到该运行时：
   ```powershell
   .\src-tauri\python-runtime\python.exe -m pip install -r backend\requirements.txt
   ```

4. 在 `tauri.conf.json` 的 `bundle.resources` 中加入：
   ```json
   "resources": {
     "../backend": "backend/",
     "../knowledge": "knowledge/",
     "../src-tauri/python-runtime": "python-runtime/"
   }
   ```

> **注意**：内嵌运行时会让安装包增大到约 80–120MB，但用户**无需安装任何东西**，
> 双击即用。这是"使用没有任何门槛"目标的推荐方案。

## 常见问题

### 编译报错 `link.exe not found`

未安装 MSVC 生成工具，或未安装「使用 C++ 的桌面开发」工作负载。

### 启动后白屏

1. 检查后端是否启动：命令行运行
   ```powershell
   .\.venv\Scripts\python.exe backend\run_server.py --no-browser
   ```
2. 若后端正常，检查 Windows 是否安装 WebView2 运行时
   （Win10 1803+ / Win11 已内置）。

### 端口 8756 被占用

后端支持 `--auto-port` 自动顺延。若需固定，修改 `main.rs` 中的 `BACKEND_PORT`。

### 打包体积过大

- 默认 NSIS 安装包约 10–15MB（不含 Python 运行时）
- 含内嵌 Python 运行时约 80–120MB
- 可通过 `strip = true`（Cargo.toml `[profile.release]`）减小 Rust 二进制体积

## 版本号更新

修改以下三处保持一致：
- `src-tauri/tauri.conf.json` → `version`
- `src-tauri/Cargo.toml` → `version`
- `frontend/package.json` → `version`
